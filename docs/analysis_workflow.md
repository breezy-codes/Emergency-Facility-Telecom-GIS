# Analysis Workflow

This document describes the analysis scripts used throughout the project and the outputs generated by each stage. The analysis combines evacuation facility locations, telecommunications infrastructure, and hazard datasets to evaluate telecommunications accessibility and hazard exposure across Australia.

## Analysis Overview

The workflow consists of five primary components:

1. Dataset overview and validation.
2. Telecommunications proximity analysis.
3. Hazard exposure assessment.
4. Spatial identification of evacuation facilities exposed to hazards.
5. Telecommunications accessibility assessment for hazard-exposed evacuation facilities.

---

## Dataset Overview

### Script

```bash
python analysis/data_overview.py
```

### Purpose

Provides summary statistics and descriptive information for the processed datasets used throughout the analysis.

Typical outputs include:

* Number of evacuation facilities by jurisdiction.
* Number of telecommunications assets.
* Dataset completeness checks.
* Spatial coverage summaries.

This step should be executed first to verify that all required datasets have been collected and processed correctly.

---

## Telecommunications Proximity Analysis

### Script

```bash
python analysis/nearest_neighbour_proximity.py
```

### Purpose

Calculates the distance between each evacuation facility and its nearest telecommunications asset.

### Outputs

* Nearest-neighbour distance calculations.
* Mean, median, minimum, and maximum distances.
* Telecommunications accessibility statistics.
* Jurisdiction-level proximity summaries.

---

## Colocation Statistics

### Script

```bash
python analysis/colocation_statistics.py
```

### Purpose

Evaluates the proportion of evacuation facilities located within specified distance thresholds of telecommunications infrastructure.

### Outputs

* Facilities within 100 m, 250 m, 500 m, and 1000 m.
* Percentage-based accessibility statistics.
* Jurisdiction-level comparisons.

---

## Flood Hazard Analysis

### Script

```bash
python analysis/flood_vs_evacuation.py
```

### Purpose

Determines the extent to which evacuation facilities intersect or are located within flood-prone areas.

### Outputs

* Number of evacuation facilities exposed to flooding.
* Exposure percentages by jurisdiction.
* Spatial overlays of evacuation facilities and flood hazard zones.

## Telecommunications Accessibility of Hazard-Exposed Facilities

### Flood Exposure

```bash
python analysis/flood_evac_celltower.py
```

This analysis identifies evacuation facilities located within flood-prone areas and evaluates their proximity to telecommunications infrastructure.

Outputs include:

* Flood-exposed evacuation facilities.
* Distance to nearest telecommunications asset.
* Accessibility statistics for flood-exposed facilities.

## Recommended Execution Order

```bash
# Dataset overview
python analysis/data_overview.py

# Telecommunications accessibility
python analysis/nearest_neighbour_proximity.py
python analysis/colocation_statistics.py

# Hazard exposure
python analysis/flood_vs_evacuation.py
python analysis/bushfire_vs_evacuation.py

# Hazard exposure and telecommunications accessibility
python analysis/flood_evac_celltower.py
python analysis/bushfire_evac_celltower.py
```

The outputs generated by these scripts form the basis of the statistical analyses, tables, figures, and spatial assessments presented in the study.
